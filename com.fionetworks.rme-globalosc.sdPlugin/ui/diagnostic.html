OSC Connection Monitor

Green RX LIVE means recent OSC packets reached the configured local UDP port. It does not authenticate their sender or prove a specific TotalMix channel works.

Press the key to send a read-only /sendall request. If TotalMix replies, the key shows RX LIVE. Yellow NO DATA or STALE means no recent feedback.

Global OSC transport

Setup checklist

1. TotalMix → Options → Enable OSC Control.

2. Settings → OSC → enabled controller → Compatibility: Global OSC.

3. Remote address: 127.0.0.1; incoming 7008; outgoing 9008.

4. Details → Send Changes, Send Status, and Send Level Data (for peak meters).

5. Press the monitor key to request state. Check the on-key RX indicator.

One application may listen on a given feedback port. Restart Stream Deck after replacing the plugin if another instance already holds it.
