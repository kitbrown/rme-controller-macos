Live Audio Peak Meter

Real audio amplitude from TotalMix Global OSC. Display-only, continuous bottom-up meter across 1–4 keys.

Audio source

Vertical meter

Use the same audio source, stack height and meter floor on all keys. Assign 1 to the physical bottom key, 2 to the key above, and so on. No labels appear on the keys.

OSC connection

TotalMix FX → Options → Settings → OSC → Global OSC controller → Details: enable Send Level Messages. This meter never sends fader or mute commands.
