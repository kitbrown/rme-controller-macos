# Current requirements — verified 2026-10-11

| Requirement | Preparation decision |
|---|---|
| Description | English; 250–1,500 characters; first 250 plain text |
| App icon | 288 × 288 static PNG |
| Thumbnail | 1920 × 960 PNG |
| Gallery | 3–10 items; images 1920 × 960 PNG; video 1920 × 1080 MP4: use under 50 MB (live Console limit) |
| Hardware integration | Real functional demo video required |
| AI use | Disclose assistance in product, metadata and media; entirely AI-created products are ineligible |
| Identity | Manifest author must match Maker organization; confirm name availability |
| Publication | Disable automatic publication; Chris approval before Submit or Publish |

Sources: [product guidelines](https://docs.elgato.com/guidelines/products/), [plugin guidelines](https://docs.elgato.com/guidelines/stream-deck/plugins/), [submission wizard](https://docs.elgato.com/maker-console/submitting-products/), [review process](https://docs.elgato.com/maker-console/review-process/), [branding](https://docs.elgato.com/guidelines/branding/).

The published gallery guideline permits under 250 MB, but the authenticated Maker Console media form explicitly limits MP4 uploads to 50 MB. Follow the stricter live limit: export under 50 MB. Live limits also show icon 2 MB, thumbnail 5 MB and gallery PNG 10 MB. The description editor displays 4,000 characters; our 1,169-character plain-text description also meets the stricter published 1,500-character guideline. Elgato estimates 4–10 working days for review; timing is not guaranteed.

Do not confuse the 288 px Marketplace icon with the packaged 256/512 px plugin icons. The latter already passed validation. Stream Deck + has a space before + in listing copy. The authenticated Console already contains this product name in FiO Networks; continue that existing draft.
