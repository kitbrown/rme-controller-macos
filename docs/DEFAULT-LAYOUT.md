# Default Stream Deck + XL Layout

## Keys

1. Main Mute
2. Dim
3. Phones Mute
4. Analog 1/2 Input Mute
5. Talkback + Dim
6. Analog 1/2 Input 48V

## Encoders

1. Hardware Input — Analog 1/2
2. Hardware Input — Analog 3/4
3. Software Playback — Analog 1/2
4. Hardware Input — SPDIF
5. Control Room — Phones 1
6. Control Room — Main

All encoders default to 0.5 dB per tick. Pressing an encoder toggles mute; rotation is blocked while muted.
